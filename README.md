# nolc-arte

Arte vectorial (SVG MAI) de **NO ONE LIKE CATS**, servido por GitHub Pages en
`https://ragosorio.github.io/nolc-arte/` — el **mismo origen** que el juego
(`https://ragosorio.github.io/no-one-like-cats/`), así que no hay CORS y las partidas no se tocan.

El arte **no** se guarda en este repo: el workflow `publish.yml` lo toma del repo del juego en cada
publicación (manual, por `repository_dispatch` o cada 6 h si cambió). Solo SVG, nunca scripts ni raster.
Detalles: `docs/part-ii/09-hosting-arte.md` en Ragosorio/no-one-like-cats.
